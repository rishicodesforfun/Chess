# Project Prerequisites - AlphaZero Chess

This document outlines the system requirements and installation steps for the AlphaZero Chess project.

## 1. System Requirements
- **Operating System**: Windows 10/11 (64-bit)
- **CPU**: x64 Architecture
- **GPU**: NVIDIA GPU with CUDA support (Recommended for training)
- **Disk Space**: ~500MB for dependencies and model, plus space for self-play data.

## 2. Software Dependencies
The following tools must be installed and added to your system's PATH:

### C++ Development (Engine)
- **CMake**: version 3.15 or higher
- **C++ Compiler**: Visual Studio 2022 Build Tools (with C++17 support)
- **ONNX Runtime**: version 1.17.1 (Automatically downloaded by CMake)

### Python Development (Neural Network)
- **Python**: version 3.10 or higher
- **PyTorch**: version 2.2.0 or higher
- **NumPy**: version 1.26.0 or higher
- **ONNX**: version 1.15.0 or higher
- **ONNX Runtime (GPU)**: version 1.17.1

## 3. Installation Steps

### Step 1: Install C++ Tools
1. Download and install [Visual Studio 2022 Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).
2. During installation, select the "Desktop development with C++" workload.
3. Download and install [CMake](https://cmake.org/download/).

### Step 2: Set Up Python Environment
1. Install [Python 3.10+](https://www.python.org/downloads/).
2. Create and activate a virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   ```
3. Install required Python packages:
   ```powershell
   pip install torch numpy onnx onnxruntime-gpu
   ```

### Step 3: Install CUDA (Optional but Recommended)
1. Install [NVIDIA CUDA Toolkit 11.8 or 12.x](https://developer.nvidia.com/cuda-downloads).
2. Install [cuDNN](https://developer.nvidia.com/cudnn) following NVIDIA's instructions.

## 4. Verification
Run the following commands to verify your setup:
- `cmake --version`
- `python --version`
- `python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}')"`
